# AetherFlow Feature Audit Matrix

Date: 2026-04-02

## Summary
- Branch: `audit/feature-matrix-2026-04-02`
- Evidence appendix: `.agent/plans/aetherflow_feature_audit_evidence_2026-04-02.md`
- Primary audit conclusion: the largest break is systemic auth transport drift between a cookie-oriented frontend and a bearer-oriented backend. The second largest break is route and tier drift introduced during remediation, followed by partially wired or schema-only features.

## Assumptions and Defaults
- This matrix is documentation-only. No runtime code, public APIs, or schemas were changed during the audit.
- Canonical route truth comes from `backend/api/routes.go`; `frontend/next.config.ts` rewrites only proxy `/api/:path*` to the backend and do not repair stale route paths.
- Evidence IDs below map directly to the appendix.

## Final Review
- Fix order should be:
  1. `ARCH-001` auth transport
  2. `ARCH-002` WebSocket transport
  3. route/tier mismatches (`FE-FETCH-001` through `FE-FETCH-007`)
  4. missing consent/security/download/task surfaces
  5. backend-only and schema-only cleanup
- Completing only the path fixes without resolving auth transport will leave most protected routes non-functional.
