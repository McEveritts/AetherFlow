# AetherFlow v4.0.1

**Released:** November 25, 2026 · **Tag:** `v4.0.1` · **Base:** `v4.0.0` (`ed38a843`) · **Channels:** `stable` (`master`) & `nightly`

AetherFlow v4.0.1 delivers the **Unified Flat Surface & Control System** across the entire Leptos WebAssembly dashboard alongside critical post-v4.0.0 reliability and hardening fixes spanning **Debian 13 fresh installation**, **Apache2 subdomain ingress & TLS synchronization**, **Jellyfin installer resilience**, **Peer Clustering WireGuard endpoint detection**, **cross-browser overlay & popup launch stability**, and a **full GitHub documentation, website, and 1440p visual showcase refresh**.

---

## Highlights

- **Unified Flat Surface & Control System (`frontend-rs`):** Retires translucent glassmorphism (`backdrop-filter`, chromatic mask rims, ambient aurora gradients, SVG noise grain, and card hover lift) in favor of a deterministic 3-tier flat surface architecture (`.af-canvas-section`, `.af-card` / `.af-surface-inset`, and crisp opaque Tier 3 `.af-modal` / `.af-drawer` / `.af-popover` / `.af-toast*` overlays) backed by 1:1 dark and light semantic `--af-*` CSS tokens, WCAG 2.1 AA contrast guarantees, atomic control color/background transitions, and a permanent Rust CI drift gate (`design_contract.rs`).
- **Opaque Overlays, WebKit Escape & App Launch Popups:** Keeps Command Palette, Notifications drawer, media previews, account/transfer popovers, and toasts fully opaque and steady on hover, restores reliable `Escape` popover dismissal on WebKit/Safari, and eliminates cross-realm `dyn_into` (`instanceof`) casts when navigating Services/Marketplace app launch popups.
- **Apache2 `default-ssl` Hijack Prevention & Post-Install Vhost/TLS Sync:** Rewrites unmodified `ServerName _` placeholders in `default-ssl.conf` to the configured base domain and wildcard aliases so alphabetically earlier `aetherflow-ext-*.conf` vhosts cannot hijack the control plane, and automatically synchronizes app vhosts and TLS certificates after Marketplace package installs.
- **Debian 13 (`trixie`) Fresh-Install Smoothness & Hardening:** Aligns `vsftpd` configuration with Debian 13/Ubuntu `vsftpd 3.0.5` TLS directives and UFW firewall provisioning, restores interactive/unattended setup logging (`OUTTO`), validates RFC-1123 hostnames and route IPv4 discovery, drops Debian `dstat`/`pcp` daemon bloat, guards optional Apache modules, and adds 1,014 lines of installer regression tests.
- **Jellyfin Kestrel Startup Retries & Conffile Restoration:** Retries transient Kestrel HTTP 503 and socket handoff errors (up to 20 attempts) while seeding the Jellyfin master user, and restores missing Debian conffiles (`--force-confmiss`) cleanly on reinstalls.
- **Smarter Peer Clustering WireGuard Endpoint Detection:** Deprioritizes VPN, overlay, container, and hypervisor virtual interfaces (`wg*`, `tailscale*`, `docker*`, `br-*`, `veth*`, `tun*`, `virbr*`, etc.) so bare-metal host NICs are recommended and selected first during `afpeer0` pairing.
- **Complete Docs, GitHub Pages & Refreshed 1440p Screenshots:** Ships the redesigned `README.md`, `docs/README.md`, `docs/design-system.md`, SVG architecture/topology graphics, GitHub Pages site (`apps/website/`), reproducible capture scripts (`scripts/docs/`), 42 dark/light 1440p screenshots (21 views × dark & light), and 33 regenerated annotated operator guide images.

## Detailed Changes Since v4.0.0

### 1. Unified Flat Surface & Control System (`frontend-rs`)
- **Semantic Token & Layer Architecture ([`frontend-rs/styles/input.css`](../../frontend-rs/styles/input.css), [`docs/design-system.md`](../design-system.md)):**
  - Introduces 100% 1:1 dark (`:root`) and light (`html[data-theme="light"]`) `--af-*` semantic surface, border, foreground, control, accent, status, focus-ring, and overlay tokens.
  - Consolidates all base flat component rules inside `@layer components` so Tailwind v4 utility classes override predictably without specificity wars, and scopes Tailwind `@source` scanning strictly to production `src/` directories (preventing test assertions from leaking `.backdrop-blur` utilities into compiled CSS).
  - Removes every `backdrop-filter`, `mask-composite`, `--obs-chromatic-*`, `--obs-specular-*`, `body::before` aurora gradient, `body::after` SVG `fractalNoise`, and card hover `translateY`/`scale3d` animation across all 16 dashboard tabs, shell chrome, editor, login, onboarding, OIDC consent, and public share routes.
  - Keeps interactive color and background switches atomic (`transition: border-color ...` only on `.af-btn`, `.af-btn-primary`, `.af-input`, `.af-tab-pill`, `.af-nav-button`, `.af-card-interactive`, and `.af-editor`) to prevent mid-transition contrast collapse during theme toggles or `:disabled` → enabled state updates across Chromium, Firefox, and WebKit.
  - Adds complete light-theme contrast remapping across status and accent utility classes (including `.text-violet-*` alongside `.text-purple-*` and high-contrast `.af-nav-active` borders).
  - Preserves McBrowser's dedicated `.af-editor[data-editor-tone="dark"|"light"]` cross-polarity styling (`>= 4.5:1` contrast regardless of outer page theme).
- **Preferences, Localization & Backward Compatibility:**
  - Retires the legacy `atmosphere` (glass/blur intensity) and `card_lift` display preferences from active UI controls and `html[data-*]` attributes while passively ignoring those keys in existing `localStorage` payloads for zero-friction upgrades and clean rollbacks.
  - Updates display/settings localization across all 6 shipped locales (`en`, `de`, `es`, `fr`, `ja`, `zh`) and wires `ConfirmDialog` default labels through active locale lookup.
- **Permanent CI Drift Gate (`frontend-rs/crates/af-web-ui/tests/design_contract.rs`):**
  - Enforces zero `backdrop-filter`, zero `mask-composite`, zero `.light ` selectors, zero legacy `.glass-*`/`.obs-tab-pill`/`.obs-telemetry-surface` classes across CSS and Rust templates, complete dark/light `--af-*` token parity, UTF-8 safe CSS comment/string parsing, and strict separation between Tier 3 overlays and Tier 2 cards.

### 2. Opaque Overlays, WebKit Escape & App Launch Popups
- **Steady Opaque Overlays (`c962b952`):** Gives Command Palette, Notifications drawer, McBrowser media/image previews, account/background-transfer header popovers, and toasts dedicated opaque `.af-modal`, `.af-drawer`, `.af-popover`, and `.af-toast` / `.af-toast-error` surfaces that stay solid and stationary on hover in both dark and light themes.
- **Reliable WebKit/Safari `Escape` Handling (`c962b952`):** Adds a window-level `Escape` key handler in `Header` so header popovers close consistently across browsers, including WebKit/Safari.
- **Cross-Realm App Launch Popup Fix (`3a8e4435`):** Fixes Services/Marketplace popup launch navigation (`frontend-rs/crates/af-web-app/src/tabs/services/launch.rs`) by replacing cross-realm `dyn_into` (`instanceof`) casts on elements created in the popup's `Document` with `unchecked_into` and a safe `body` → `documentElement` container fallback, backed by Playwright regression coverage in `e2e/tests/e2e/wasm.operator-parity.spec.ts`.

### 3. Apache2 Ingress Hardening & Post-Install Vhost/TLS Sync (`bf98b002`)
- **`default-ssl.conf` Hijack Prevention:** Updates `setup/modules/04-security.sh` and `backend-rs/crates/af-runner/src/ingress_vhost.rs` to rewrite unmodified `ServerName _` placeholders in `default-ssl.conf` to the configured public base domain and wildcard aliases (preserving operator-customized configs), preventing alphabetically earlier `aetherflow-ext-*.conf` vhosts from intercepting control-plane HTTPS traffic.
- **Automatic Post-Install Ingress & TLS Synchronization:** Hooks Marketplace job completion (`backend-rs/crates/af-api/src/routes/marketplace/job_runner.rs`) and the runner lifecycle coordinator (`backend-rs/crates/af-runner/src/package_lifecycle/coordinator.rs`) to reconcile app vhosts and TLS certificates automatically after package installs, with unit and Apache hygiene regression coverage (`backend-rs/crates/af-runner/src/package_lifecycle/tests/coordination.rs`, `tests/test_setup_apache_hygiene.py`).

### 4. Debian 13 (`trixie`) Fresh-Install Smoothness & Hardening (`446815fd`)
- **`vsftpd` 3.0.5 & UFW Firewall Alignment:** Updates `setup/templates/vsftpd.conf.template` and `setup/modules/04-security.sh` to Debian 13/Ubuntu `vsftpd 3.0.5` directives (`ssl_tlsv11=NO`, `ssl_tlsv12=YES`, `ssl_tlsv13=YES`, `listen_port=21`), adapts TLS keys across `vsftpd 3.0.3`/`3.0.5`, removes raw `iptables -I INPUT` pre-injection so `_setup_firewall` does not skip UFW setup, surfaces `vsftpd` restart failures, validates `passive_ip` as canonical IPv4, adds symlink/non-regular-file guards, and stages `0600 vsftpd.pem` atomically.
- **Setup Logging (`OUTTO`) & Hostname/IPv4 Reliability:** Removes top-level `OUTTO=/dev/null` from `setup/modules/05-finalize.sh` in favor of function-local defaults so interactive installs prompt cleanly in `_logcheck` and unattended installs log to `/root/AetherFlow.<PPID>.log`; validates requested hostnames against RFC-1123 with atomic writes and resume propagation; preserves `/root` `0700` permissions; parses `src` IPv4 safely across `/32` and offline routes; and updates the completion banner with the bootstrap token path and working `af service` commands.
- **Package Hygiene & Regression Suite:** Drops virtual `dstat` from Debian `_depends` (avoiding `pcp` daemon bloat), moves Ubuntu `dool` to the `apt-cache`-gated optional loop, guards missing Apache `scgi`/`fastcgi` modules (enabling `fcgid` when present), updates the `ffmpeg` APT step label, and adds comprehensive regression coverage in `tests/test_installer_smoothness_regressions.py` (+1,014 lines).

### 5. Jellyfin Installer & Peer Clustering Endpoint Hardening
- **Jellyfin Kestrel Retry & Missing Conffiles (`c1bb80e5`):** Retries transient HTTP 503 and connection/socket handoff errors (up to 20 attempts, 1s backoff) inside `seed_jellyfin_master_user` (`packages/lib/systemd_credentials.sh`) and passes `-o Dpkg::Options::="--force-confmiss"` during `apt-get install jellyfin` (`packages/package/install/installpackage-jellyfin`) so deleted Debian conffiles are cleanly restored on reinstall, with contract coverage in `tests/test_marketplace_remover_contracts.py`.
- **Peer WireGuard Endpoint Prioritization (`ffeb0fcf`):** Classifies and deprioritizes VPN, overlay, container, and hypervisor NAT interfaces (`wg*`, `tailscale*`, `utun*`, `tun*`, `tap*`, `docker*`, `br-*`, `veth*`, `podman*`, `cni*`, `flannel*`, `calico*`, `cali*`, `cilium*`, `kube*`, `nerdctl*`, `virbr*`, `lxcbr*`, `lxdbr*`, `incusbr*`, `vboxnet*`, `vmnet*`) in `backend-rs/crates/af-api/src/peers/mod.rs` so directly reachable bare-metal NICs rank first during WireGuard pairing.

### 6. Documentation, Release Automation & 1440p Visual Showcase
- **Release Workflow Concurrency (`bd4014ab`):** Adds `concurrency` (`cancel-in-progress: true`) to `.github/workflows/release.yml` so superseded release runs cancel cleanly.
- **GitHub Presence & Website Refresh (`e209b365` + v4.0.1 refresh):** Rewrites `README.md`, adds `docs/README.md` and `docs/design-system.md`, introduces custom SVG architecture/peer-clustering/banner graphics, redesigns the GitHub Pages site (`apps/website/`), updates `scripts/docs/capture_screenshots.mjs` and `scripts/docs/capture_guides.mjs` for flat `.af-*` selectors, and refreshes **42 dark & light 1440p screenshots** (21 views including Login, Command Palette, McBrowser Editor, and Cluster Transcode) plus **33 annotated step-by-step operator guide PNGs**.

## Breaking Changes & Upgrade Guide

**No breaking changes from `v4.0.0`.** There are no new SQLite schema migrations, no environment variable renames, and no breaking API or CLI changes between `v4.0.0` and `v4.0.1`. Legacy `atmosphere` and `card_lift` display preferences stored in browser `localStorage` are safely ignored without error.

> [!NOTE]
> Upgrading directly from **`v3.2.x`**? Review the [v4.0.0 Release Notes](./v4.0.0.md#breaking-changes--upgrade-guide) and [Upgrading Guide](../upgrading.md) first (Migration 26 retires legacy master/worker clustering).

### Upgrading from `v4.0.0` or `v4.0.0-nightly.*`

1. **Optional pre-upgrade snapshot:** Create a WAL-safe backup via **Settings → Backups & Restore** or `sudo af backup create`.
2. **Deploy `v4.0.1`:**
   - From the Web UI: **Settings → System Updates** → select the **Stable** (or **Nightly**) channel and click **Update**.
   - From the CLI:
     ```bash
     # Stable channel (master / v4.0.1)
     sudo af release deploy --channel stable

     # Nightly channel (rolling v4.0.1-nightly.* prereleases)
     sudo af release deploy --channel nightly

     # Direct in-process fallback (without runner socket)
     sudo af release deploy --local --channel stable
     ```
3. **Rollback:** If `/health/ready` fails after the atomic symlink swap, `af-release` restores `.previous_release` automatically. Manual rollback: `sudo af release rollback --local`.
