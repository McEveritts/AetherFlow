# AetherFlow v4.0.0

**Released:** November 25, 2026 · **Tag:** `v4.0.0` · **Commit:** `ed38a843` · **Base:** `v3.2.7`

AetherFlow v4.0.0 promotes the pure-Rust control plane and Leptos WebAssembly dashboard from `nightly` to `master` (`stable`). It completes the Zero-Go cutover—retiring the Go backend, Redis runtime, and embedded Next.js bundle—while introducing Peer Clustering with NFSv4.2 media sharing and remote Jellyfin 12.4 transcode offloading, Native McBrowser, native Rust LibreSpeed, canonical streaming analytics, WireGuard/Tailscale networking, isolated SLSA-verified self-updates, and an expanded 77-app bare-metal catalog.

**By the numbers (`v3.2.7...v4.0.0`):** 373 commits (367 non-merge) · 2,233 files changed (+655,777 / −257,910 lines) · 16 Rust crates (12 backend compiling 4 binaries + 4 WASM frontend) · 77 bare-metal Marketplace apps across 9 categories (+5 new) · 9 opt-in declarative Rust recipes · SQLite migrations 20–27 · 0 Go files.

## Highlights

- **Pure-Rust Control Plane & External Leptos WASM Dashboard (`Zero-Go`):** Replaces the Go backend, Redis dependency, Go plugin SDK, and embedded Next.js SPA with the 12-crate Rust workspace (`backend-rs`: `aetherflow-api`, root Unix-socket `aetherflow-runner`, `af` admin CLI, `speedtest-backend`, and `af-transcode`) paired with the 4-crate Leptos 0.8 WASM dashboard (`frontend-rs`) shipped as external `web/dist` assets.
- **Peer Clustering & Distributed Jellyfin 12.4 Transcoding:** Links independent Debian 13 (`trixie`) AetherFlow servers over a dedicated `afpeer0` WireGuard mesh with 8-area delegated grants, remote server switching, cross-peer NFSv4.2 media folder sharing (`/v1/peer-storage`), remote Jellyfin 12.4 `ffmpeg` offloading (`af-transcode` / `af-transcode-worker.service` with secret-free `/etc/aetherflow/transcode.env`), and read-only `af cluster diagnose <link>` diagnostics.
- **Native McBrowser (`af-files`):** Adds a capability-scoped per-user file manager backed by Linux `openat2` confinement (`/var/lib/aetherflow/mcbrowser/user-<id>`, `0700`) with 64 GiB resumable TUS uploads, ETag-guarded 10 MiB UTF-8 editing in a native Rust/Leptos code editor (45 syntax modes, Markdown/MathML preview), 9-format archives, previews, password-protected public shares, and FlowAI smart search.
- **77-App Bare-Metal Marketplace & Native Rust LibreSpeed:** Expands the catalog from 72 to 77 native Linux apps across 9 categories (+5: **Palate**, **Maintainerr**, **Tailscale**, **Piped** *(Experimental)*, **Invidious** *(Experimental)*), adds 9 opt-in declarative Rust package recipes in `af-runner`, replaces Go `speedtest-go` with native Rust `af-librespeed` (`speedtest-backend`) with BoltDB v2-to-SQLite migration, and hardens exact version pinning, receipts, and rollbacks.
- **Canonical Streaming Analytics & Network Control Center:** Introduces canonical streaming history, patterns, drilldowns, batch imports, reconciliation, and 8 MiB JSON / 128 MiB CSV portability across Jellyfin, Plex, and Emby, alongside a dedicated **Network** tab for persistent WireGuard (`wg0`) client peers (one-time keypair/QR handoff) and Tailscale login, subnet routes, and exit-node controls.
- **Isolated Self-Updates, Hardened Security & Plugin Sandbox:** Runs atomic `af-release` updates inside per-launch transient systemd units with WAL-safe pre-swap SQLite backups, `/proc/<pid>/exe` verification, and zero-PyPI Sigstore Rekor v1/v2 + SLSA v1 provenance verification; isolates managed plugins under `DynamicUser=yes` transient systemd units (`systemd >= 249`, cgroup v2) and enforces human-gated FlowAI approvals, OIDC PKCE/device consent, and unified session revocation.

## Breaking Changes & Upgrade Guide

Before upgrading, review the full [Upgrading Guide](../upgrading.md) and [Self-Update Lifecycle](../self-update.md), and ensure `python3` and `openssl` are installed on the host.

### Key Breaking Changes

- **Migration 26 — Legacy Master/Worker Clustering Retired:** Permanently drops `cluster_nodes`, `cluster_enrollment_tokens`, and `cluster_commands`, and retires all `CLUSTER_*` environment variables (`CLUSTER_MODE`, `CLUSTER_MASTER_ADDR`, `CLUSTER_PSK`, `CLUSTER_CA_CERT`, `CLUSTER_SERVER_CERT/KEY`, `CLUSTER_CLIENT_CERT/KEY`) and `/api/v1/admin/cluster/*` routes. Create a WAL-safe backup before upgrading and re-pair previously enrolled servers from the **Cluster** tab.
- **Zero-Go, Redis & Next.js Removed:** `backend/`, `frontend/`, `plugins/sdk-template/`, and Redis runtime dependencies are removed. No Go, Node.js, or Redis daemons are required at runtime.
- **Canonical Asset & Config Paths:** Package catalogs live in root `config/` (replacing `backend/config/`); dashboard assets live externally in `web/dist` (or `STATIC_DIR`); systemd units read `/etc/aetherflow/aetherflow.env` directly (legacy `/opt/AetherFlow/current/backend/.env` unit fallbacks retired; the release engine migrates legacy slots during upgrade).
- **Tightened Auth, Host Validation & Ingress Defaults:**
  - `host_validation_middleware` trusts canonical loopback IPs only by default—add your host's LAN/public IP to `ALLOWED_HOSTS` in `/etc/aetherflow/aetherflow.env` if accessing the dashboard directly by IP.
  - All 10 gateway-protected apps (including `rutorrent`) require admin authentication on `*.aether.local` by default (`AF_ALLOW_UNAUTH_LOCAL_LAN=1` opts in for RFC 1918/link-local/ULA). Updating `rutorrent` migrates loopback Basic Auth to `/etc/aetherflow/rutorrent-proxy-token.conf`.
  - `/metrics` requires `METRICS_BEARER_TOKEN` or an active admin session unless `METRICS_PUBLIC=1`.
  - Production startup fails closed on weak `JWT_SECRET` (`< 32` bytes) or missing `AES_MASTER_KEY`, and legacy unsalted 64-hex SHA-256 2FA recovery codes are rejected fail-closed (sign in with TOTP and regenerate bcrypt recovery codes in **Settings → Security**).
- **Apache Streaming Timeouts & Channel Consolidation:** Existing hosts should raise Apache proxy I/O timeouts to `3600s` for long-lived media streams (applied automatically on new setups). The `experimental` release channel is retired and aliases to `nightly`.

### Upgrading to v4.0.0

1. **Take a WAL-safe backup first** (required before Migration 26 if you may ever need to roll back across schema changes): via **Settings → Backups & Restore** (or `sudo af backup create` on v4 nightly hosts). Never copy a live WAL `.sqlite` file while `aetherflow-api.service` is running.
2. **Trigger the upgrade:**
   - **From `v3.2.x` (pre-isolation runner):** Upgrade from **Settings → System Updates** or run the standalone root jump:
     ```bash
     sudo /opt/AetherFlow/current/deploy/release-manager.sh deploy --channel stable
     ```
   - **From `v4.0.0-nightly.*`:**
     ```bash
     sudo af release deploy --channel stable
     # Or run in-process without the runner socket:
     sudo af release deploy --local --channel stable
     ```
3. **Rollback:** If `/health/ready` fails after the symlink swap, the release engine automatically restores `.previous_release`. To roll back manually on v4 hosts, run `sudo af release rollback --local`. See [Upgrading Guide](../upgrading.md#sqlite-rollback-behavior) for schema rollback steps.

## Known Limitations

- **Peer Clustering:** Requires **Debian 13 (`trixie`)** with direct WireGuard reachability (no NAT traversal or relays), does not provide HA or service failover, binds `nfs-server.service` exclusively to `afpeer0` when exports or transcoding are enabled, and supports **Jellyfin 12.4** only for distributed transcoding (not Plex or Emby).
- **McBrowser & Streaming:** McBrowser's WASM workspace UI currently sends `"conflict": "error"` on copy/move/rename and does not yet implement Shift-click range selection, explorer-wide keyboard shortcuts/clipboard, or recursive folder drag-and-drop; Streaming UI session controls are enabled for Jellyfin only (Emby item-summary sync returns HTTP `501`); **Piped** and **Invidious** remain experimental packages subject to upstream YouTube anti-bot changes.
- **Verification Scope:** Release verification covers source checks, unit/contract suites, multi-browser Playwright runs, and native ARM64 release smoke tests; it does not claim live production installation of every catalog application.
